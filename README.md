# Gen-Z Translator

## Functionality/Purpose
Parser that tokenizes user input and cross-references it against a custom dictionary using hash maps for O(1) slang lookup, translation, and definition retrieval.
Tracks and displays real-time slang-word frequency as the sentence is processed.

## Background
Collaborated in a 4-person team to build a CLI slang-translation tool from scratch in under 8 hours at a hackathon.
